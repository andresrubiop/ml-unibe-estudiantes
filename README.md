# Machine Learning · Laboratorios (UNIB.E)

Notebooks del módulo Machine Learning de la Maestría en Big Data y Ciencia de Datos, Posgrado de la Universidad Iberoamericana del
Ecuador. Se abren desde el aula del curso, en Google Colab, o en tu equipo con `uv sync` y JupyterLab.

- `sesion-1/` · `sesion-2/` · `tutorias/`: laboratorios para trabajar.
- `soluciones/`: versiones resueltas.
